One funny line from a hopeless tech support agent to a desperate customer:
the agent admits the classic "turn it off and on again" is genuinely his
entire plan — cheerful, useless, and out of ideas. The program writes that
single line to `/output/entry.txt` and self-checks the 199-character gate.

Run it with Node 22 (no dependencies):

```sh
node main.ts
```

Entry for the [Have You Tried Turning It Off?](https://make.fun/c/u-motasimfuad-have-you-tried-turning-it-off-154a938b) competition on make.fun.
